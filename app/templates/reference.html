Sending from your control system



  

    
Shell / anything with netcat


echo "FADE 2 1s" | nc -u -w1 {{ udp_ip }} {{ s.udp_port }}
python tools/udp_send.py {{ udp_ip }} {{ s.udp_port }} "PVW 3; CUT"

    
HTTP (curl, Companion HTTP, anything)


curl "{{ base_url }}api/v1/cmd?c=FADE+2+1s&format=text"{% if api_key_set %} \
     -H "X-API-Key: <key>"{% endif %}
OK FADE 2 25 ME1

curl -X POST {{ base_url }}api/v1/cmd -d "FTB"{% if api_key_set %} -H "X-API-Key: <key>"{% endif %}

curl "{{ base_url }}api/v1/status?format=text"
OK CONNECTED {{ status.connection.product or 'ATEM' }} PGM=1 PVW=2

    
HTTP status is 200 when every command succeeded, 422 otherwise. JSON by default: {"ok": true, "replies": ["OK FADE 2 25 ME1"]}.

  

  

    
Q-SYS (Lua)


local setter = UdpSocket.New()
setter:Open("0.0.0.0", 0)
setter.Data = function(sock, pkt) print("Setter:", pkt.Data) end

function cue(cmd) setter:Send("{{ udp_ip }}", {{ s.udp_port }}, cmd .. "\n") end

Controls["Fade Cam 2"].EventHandler = function() cue("FADE 2 1s") end
Controls["Go to black"].EventHandler  = function() cue("FTB") end
Controls["Aux1 PGM"].EventHandler     = function() cue("AUX 1 PGM") end

    
Full version with status parsing: docs/qsys_integration.lua in the repository.

    
Crestron

    
SIMPL: a UDP Client symbol at {{ udp_ip }} port {{ s.udp_port }}; send the string with \n. SIMPL#: UDPClient.SendData("FADE 2 1s\n"). Parse the reply by its first word.

    
Bitfocus Companion

    
Generic UDP connection to {{ udp_ip }}:{{ s.udp_port }}, one Send message action per button; or the Generic HTTP module with GET {{ base_url }}api/v1/cmd?c=….
